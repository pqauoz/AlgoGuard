# Research Artifacts

This folder keeps the notebook-driven research workspace separate from the Flask runtime app.

- `dataset/`: raw and processed research datasets.
- `models/`: ignored experiment model artifacts generated by notebooks.
- `notebooks/`: exploratory and model-comparison notebooks.
- `results/`: exported research metrics and comparison tables.

The main AlgoGuard web app does not import from this folder at runtime.

Generated model and processed-data folders are intentionally empty in the clean
repository baseline. Running the notebooks may repopulate them locally, but
their generated contents remain ignored by Git.

These files are archived research evidence. Some notebooks and result tables use
earlier experimental model combinations and do not define the current runtime
architecture. The active application implementation lives in `services/` and is
verified by `tests/`.
